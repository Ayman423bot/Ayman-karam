ELITE English — نسخة تشغيل حقيقية قابلة للتطوير

التشغيل:
1) ثبّت Python 3.11+.
2) pip install -r requirements.txt
3) (اختياري وأفضل) ضع متغيرات البيئة:
   ADMIN_PASSWORD=ATEF1112233
   SECRET_KEY=غيّر_هذا_المفتاح
4) python app.py
5) افتح http://127.0.0.1:5000
6) لوحة الإدارة: /admin/login

مهم:
- هذه نسخة MVP حقيقية بقاعدة SQLite وتسجيل دخول للإدارة وإدارة الدروس والإعلانات والطلاب.
- رابط Live يمكن وضعه من لوحة الإدارة.
- واجهة AI الحالية تجريبية؛ لربط AI حقيقي يجب إضافة مفتاح API على السيرفر وعدم وضعه في كود المتصفح.
- قبل النشر العام غيّر SECRET_KEY وكلمة مرور الإدارة إلى أسرار محفوظة كمتغيرات بيئة، وأضف HTTPS وCSRF وإدارة حسابات الطلاب.
